# .local/

Gitignored, machine-local files (this README is the only tracked file here). The repository is
public, so anything personal lives here and nowhere else:

- `accounts.md`: the real accounts, server and paths behind the placeholders used in the docs
  (`<readonly-account>`, `<test-account>`, `<server>`, `<admin-key-file>`, …), with their rules.
- `linux-vm.txt`: `user@host` of the Linux VM used by tools/linux.ps1 (first non-comment line).

If you are an agent and these files are missing, ask the user; never guess real values.
