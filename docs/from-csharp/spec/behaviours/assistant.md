# Behaviours: AI assistant (`src/ai.rs`, `src/agent.rs`)

Area: `AI`. Owner milestone: M6 (assistant column, settings), M3 (composer rewrite menu). Since 2026-11-21 (decision D-M6b-08) the assistant is a **bundled native add-on** (`plugins/Barbican.Plugin.Assistant`), not app core: its behaviour is unchanged, it is delivered through the native add-on host services (settings rows, secrets, HTTP, host tools, dialogs, chat panel) and can be turned off in Settings > Add-ons. Tests named below are in `tests/Barbican.Plugin.Assistant.Tests` unless a project is named.
Added at the M0 review (stream m0-review): the catalogue streams had no row for these modules.
Bulwark has no built-in assistant; this is a Barbican addition, so most rows have no Bulwark ref.
No Rust tests exist for either module.
