Barbican mockups

53 static screens of Barbican (a Rust mail, calendar, contacts and files client for Stalwart, a functional clone of Bulwark webmail for the features the owner uses) drawn in the visual language of the markdown-shared-rs toolkit (mdshared-ui), desktop width only. Every screen has a light/dark switch. All people, addresses and data are made up (example.com, example.org). Each file starts with an HTML comment listing the toolkit widgets it needs and the ones marked NEW, each with the K item that would provide it. Revised after the feature cut says what was removed.

How it is built.
  • tokens.css: the toolkit's look as CSS custom properties named after its own tokens (palette fields, Sizes, widget constants), each with its source file; values the toolkit lacks say invented.
  • tokens-skin-*.css: the same names with other values. The Skins screens link one of them instead of tokens.css and change nothing else.
  • icons.css: the toolkit's glyph.rs paths (16 grid, 1.25 stroke, round ends) plus invented ones in the same style, as CSS masks.
  • kit.css: one class per widget, reading only tokens.
