- The avatar refresh clears in-memory and profile-local cache and invalidates in-flight work. It uses a separate background disk lock so UI requests do not wait on disk IO; no artificially slow filesystem test was run.

Files thumbnail display is not implemented even though its preference can be stored. Accessibility reset runs per-setting writes and can be partial if a later write is refused.
