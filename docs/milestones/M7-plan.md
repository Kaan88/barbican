## Security, account and concurrency contracts

- User enters the admin key; agents never read the admin key file or use its key. Use profile-scoped `ISecretStore` (`src/Barbican.Platform/ISecretStore.cs`, `App/Composition/PlatformServices.cs`) and a separate admin-client factory. Keep credentials out of preferences, logs, screenshots, URLs, errors, backups and plugin payloads; clear secret-bearing buffers/state on sign-out, page disposal and profile switch. Automation uses in-memory synthetic credentials only. Never exercise admin writes on a live server; fake-only includes queue, spam, policy and actions. Any optional live admin read requires the user to enter credentials and remains unproven until performed; do not ask for, extract or reuse them.
- Scope each client, policy snapshot, editor and result to a captured profile, endpoint, account and monotonic generation. Cancel or discard late results after change, including A-to-B-to-A. A confirmed action already sent remains tied to its captured original target; represent cancellation or lost acknowledgement as unknown and refresh before retry. Reject stale rendered callbacks and old form submissions. No background refresh may replace dirty form fields.
- Gate navigation and operations by verified capabilities and permissions; retain structured method errors, partial results and retryable failures. Use typed allowlisted methods and validated destinations. Defend against hostile data, oversized lists, missing fields, redirects and cross-origin credential forwarding. Destructive and bulk operations identify target/scope, require explicit confirmation and never claim success from an empty or unrelated acknowledgement. Secrets issued by server are one-time display and cleared promptly.
- Use state/ETag conditional saves where the actual backend provides them. Bulwark policy route uses `If-Match` and returns conflict (`app/api/admin/policy/route.ts:28-31,152-156`); on conflict preserve the draft and offer reload/merge. Do not fake atomicity across distinct writes or report an unsupported concurrency guarantee.
